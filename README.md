# Healthy Zoo 🐾

เว็บแอปแบบมือถือสำหรับคำนวณแคลอรี่และโปรตีนต่อวัน พร้อมโปรแกรมออกกำลังกาย ธีมสัตว์น่ารัก

## ฟีเจอร์
- ตั้งค่าโปรไฟล์ + เลือกสัตว์คู่หู → คำนวณ BMR / TDEE / เป้าแคล / โปรตีน / คาร์บ / ไขมัน
- บันทึกอาหาร 4 มื้อ ค้นหาจากรายการอาหารไทย หรือกรอกเอง (บันทึกเป็น "ของฉัน" ได้)
- หน้าหลัก: วงแหวนแคลที่เหลือ, ความคืบหน้าโปรตีนแบบรอยเท้า 🐾, สัตว์คู่หูให้คำแนะนำ, นับวันต่อเนื่อง
- โปรแกรมออกกำลัง 7 แบบ (หมี กระต่าย แมว จิงโจ้ กอริลลา กบ ปู) บอกจำนวนนาที ท่า เซต
- โหมดออกกำลังแบบนำทีละท่า มีจับเวลา พัก เสียงเตือน และสรุปแคลที่เผาผลาญ
- บันทึกกิจกรรมอื่น (เดิน วิ่ง ปั่น ว่ายน้ำ ฯลฯ) คำนวณจากค่า MET
- ข้อมูลเก็บใน localStorage ของเครื่อง · ติดตั้งเป็นแอป (PWA) และใช้ออฟไลน์ได้

## สูตรที่ใช้
- BMR (Mifflin-St Jeor): ชาย `10W + 6.25H − 5A + 5`, หญิง `10W + 6.25H − 5A − 161`
- TDEE = BMR × ระดับกิจกรรม (1.2 / 1.375 / 1.55 / 1.725)
- เป้าแคล = TDEE − 500 (ลดไขมัน) / ±0 (รักษา) / +300 (เพิ่มกล้าม) ขั้นต่ำ 1,500 (ชาย) / 1,200 (หญิง)
- โปรตีน 1.8 / 1.4 / 2.0 g ต่อน้ำหนักตัว 1 กก. · ไขมัน 25% ของแคล · คาร์บ = ส่วนที่เหลือ
- แคลที่เผาผลาญ = MET × น้ำหนัก (กก.) × ชั่วโมง

## รันในเครื่อง
เป็นไฟล์ static ล้วน ไม่ต้อง build แต่ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เพราะใช้ ES modules)

```
python -m http.server 8000
```
แล้วเปิด http://localhost:8000

## Deploy ขึ้น GitHub Pages
1. push โค้ดขึ้น branch `main`
2. ไปที่ **Settings → Pages** ของ repo
3. Source: **Deploy from a branch** → Branch: `main` / `/ (root)` → Save
4. รอสักครู่ แล้วเปิด `https://<username>.github.io/healthy-fitness/`

> เมื่อแก้ไฟล์แล้ว deploy ใหม่ ให้เปลี่ยนเลข `CACHE` ใน `sw.js` เพื่อให้เครื่องผู้ใช้โหลดเวอร์ชันใหม่
